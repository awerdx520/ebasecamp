### 关键判定规则

**B4（派生 name 判定，保守优先 + 语义折衷显式化）**
- *前置探测（必须先做）*：用一份**显式写了顶层 `name:`** 的最小 compose 跑真实 `docker compose config --format json`，确认 `configs`/`secrets` 条目的 `name` 前缀究竟是顶层 `name` 还是目录名。探测结果写进实现注释与 ERT 注释。
- 派生前缀候选（按探测结果排序，探测前先按 ①顶层 `name` ②源文件父目录名 ③项目名 三者都试）：条目 `name` 等于 `(format "%s_%s" PREFIX 键)` 即视为派生 → 删除该 `name` 键。
- 三候选都匹配不上 → **保留**。
- *语义折衷（必须记录）*：若用户显式写的 `name` 恰好等于派生格式，会被判为派生而删除 —— `--no-interpolate` 的 JSON 无法区分二者，接受该折衷；用一条 ERT 固化「显式恰好等于派生值时被删除」，避免行为悬空。

**B5（幂等清理与 close 最终顺序）**
- `--teardown-session`：先判全局 `ebasecamp-ui--session` 为 nil 则直接返回（幂等门）；否则依次 `remove-hook` ×2 → 停轮询 → 取消提示定时器 → 全局 session 置 nil。
- `ebasecamp-ui-close` 最终顺序（写死，执行时照此实现）：**取 session 快照 → teardown → 用快照调用 `--save-ui-state`（否则 session 已 nil 会跳过落盘）→ `etaf-unmount` → `kill-buffer`**。
- `ebasecamp-ui--save-ui-state` 改为 `(&optional session)`，内部改为 `(if session (etaf-value (ebasecamp-ui-session-split-ratio session)) (ebasecamp-ui--current-split-ratio))`。**这是 B5 的关键改动**：teardown 已把全局 session 置 nil，若不传快照就会落盘默认宽度 0.26，引入「拖到一半直接关闭时宽度回退」的回归。
- `etaf-on-unmounted` 回调改为调用 teardown（不再自己 stop/cancel，避免双份逻辑）。
- 幂等门只看全局 session；`on-unmounted` 闭包捕获的是渲染期局部 `session`，需实测确认（见「需实测」#3）。
- 用例②：正常 `close` → 钩子归零、session nil、**`ui-state.el` 落盘的 ratio 等于 close 前快照值（不等于默认 0.26）**——守住快照语义，而不只是「文件被写入」。
- ADR-0011 需标注「扩展 ADR-0003 的 close 收尾描述」（若 ADR-0003 提及 close 顺序），保持决策链路完整。
- *行号更正（2026-10-30 实测）*：主题钩子 install 在 `lisp/ebasecamp-ui.el:521-527`、remove 在 `529-534`（**533 / 534 正是要复用的两条 `remove-hook`**）、会话 struct 段起 `536`（`cl-defstruct ebasecamp-ui-session` 在 538）、`etaf-on-unmounted` 在 `2832-2835`、`ebasecamp-ui-close` 在 `3158`（现实现顺序 `3164-3174`）。原文「515-534」已失配（该区间现为主题钩子），执行时按上述位置重新定位。

**B7（skip 机制与基线口径）**
- 2 条用例必须带 `(skip-unless (and (require 'avy nil t) (fboundp 'avy-process)))`：`make test`（无 avy load-path）下 skip 不红，`make test-avy`（追加 `-L $(STRAIGHT_BUILD)/avy`）下真实运行。
- 基线口径明确为（按 ERT 实测输出格式）：`make test` = **`Ran 494 tests, 492 results as expected, 0 unexpected, 2 skipped`**；`make test-avy` = 全量 **`Ran 494 tests, 494 results as expected, 0 unexpected`**（2 条 avy 用例转 pass）。两项都要在 CHANGELOG 与 AGENTS 写清。
- 先探测 `$(STRAIGHT_BUILD)/avy` 是否存在；不存在 → B7 标 **BLOCKED**，不改 `Makefile`、不写用例，报告中说明。
